# DURGA AI

**Dynamic, Unified, Risk-aware Guardian AI** — premium women-safety companion UI (Expo + React Native + TypeScript).

Indigo / violet design system · mock Ahmedabad data · fully navigable demo.

## Run

```bash
cd durga-ai
npm install
npx expo start --lan --clear
```

## Screens

| Screen | What to show |
|--------|----------------|
| Home | Safety score, quick actions, HOLD FOR SOS |
| Map | Zones, search, safest vs fastest, report |
| DURGA | Guardian chat, prompts, voice CTA, actions |
| Contacts | Trusted Guardians + add contact |
| Device | IoT control center (dark) |
| Emergency | Full SOS mode + swipe to stop |
| Nearby Help | Map preview + places |
| Offline | Reassuring offline capabilities |
| Settings | Profile / safety / privacy |

SOS is a **floating red action** (long-press) — not a normal tab.
