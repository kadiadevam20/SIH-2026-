# DURGA AI

The Expo app lives in the `durga-ai` folder.

## Quick start

```bash
cd durga-ai
npm start
```

## Phone preview

1. Install **Expo Go** on your phone
2. Run `npm start` in `durga-ai`
3. Scan the QR code in the terminal (same Wi‑Fi)

For tunnel mode: `npm run start:phone`

Manual URL (replace with your PC IP):

```
exp://192.168.29.113:8081
```
