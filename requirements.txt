# Verified compatible with Python 3.14.3 as of August 2026.
# Every package below is free/open-source (no paid SDK, no paid API key).

# NOTE on uvicorn: we intentionally install plain `uvicorn`, NOT
# `uvicorn[standard]`. The [standard] extra pulls in uvloop/httptools,
# which are C-extension packages that can lag behind brand-new CPython
# releases on Windows (no prebuilt wheel yet -> pip tries to compile from
# source -> fails without a C compiler). Plain `uvicorn` is pure-Python,
# installs reliably on a fresh Python 3.14.3 + Windows setup, and is more
# than fast enough for this app. If, by the time you install this, Windows
# wheels exist for uvicorn[standard] on 3.14 and you want the extra
# performance, you may switch to it — see README "Troubleshooting".
